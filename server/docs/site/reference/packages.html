包速查表

server/internal/pkg/ 下全部 58 个 Go 包的一句话索引(52 个一级目录 + 6 个子包)。 想知道"有没有我要的能力",先翻这张表;想知道"怎么用",点进对应章节。

命令自查:

cd server
go list -f '{{.ImportPath}} {{.Doc}}' ./internal/pkg/...

基础设施(17)

包 一句话 章节
logger 多 Core 装配:控制台 + info/warn/error/audit/access 分文件,按天按级别 rotator,脱敏钩子 logger
errcode 业务错误码:按业务域分段,Error 类型,code → HTTP 状态映射 errcode
response 统一响应体:成功 / 失败 / 分页三种形状 response
validatorx 统一参数校验:自定义规则(cn_phone / idcard)+ 中文错误 validatorx
pagination 分页参数:PageRequest / Normalize / Offset,size 上限 100 pagination
jsonid 主键以字符串上 wire;另带一个"找出漏了 ,string 的字段"的扫描器 jsonid
sonyflake 分布式 ID 生成(17 位数字,东八区起始时间)+ worker id 分配 sonyflake
timeutil 统一东八区的时间工具 timeutil
buildinfo 编译期构建信息注入(-ldflags -X) buildinfo
syncx 并发原语集合:单飞 / 优雅关停 / 计数信号量 / worker pool / 计数器 syncx
randomx 安全随机 token 生成(不用 math/rand) randomx
retryx 指数退避重试 + 抖动 retryx
uainfo 解析 User-Agent,取出浏览器与操作系统 uainfo
metricsx Prometheus 指标注册 + /metrics handler metricsx
otelx OpenTelemetry TracerProvider 初始化(关闭时是 noop) otelx
apiverx API 版本协商(X-API-Version 头) apiverx
grayx 灰度发布分组 header 透传 grayx

存储与缓存(5)

包 一句话 章节
cachex 两级缓存(L1 本地 LRU + L2 Redis)+ 三防(单飞 / 空值占位 / TTL 抖动) cachex
kvstore 计数 + 滑动窗口的键值存储;限流与登录锁定都落在它上面 kvstore
searchidx 加密字段的全文搜索(盲索引) searchidx
media 媒体探测:ffprobe 读时长/分辨率,ffmpeg 抽封面帧 / 转码 media
oss 对象存储统一抽象(本地磁盘 / 阿里云 OSS)+ 上传凭证等高级特性 oss

包 一句话 章节
auth JWT 签发 / 解析 / 吊销 + 强制下线(typ 三态 + JTI + aud) auth
authz 资源级鉴权原语:principal / grant / 数据级断言 authz
casbinx Casbin 初始化 + 策略行格式 casbinx

desensitize 请求体 / 查询串脱敏,供审计采集端使用 desensitize

loginlock 登录失败计数 + 账号锁定 loginlock

scope 数据范围(行级权限):规则 → 作用域 → WHERE 条件 scope
fieldpolicy 字段级可见性(列级权限):三态模式 + 逐字段叠加 + 响应出口脱敏 fieldpolicy

internal/ 下的其它目录(不是框架原语)

目录 作用
internal/api Hertz 路由 / 中间件 / handler —— 业务接口层
internal/service 业务 service —— 业务代码
internal/model GORM 实体 —— 业务表结构
internal/repository DB / Redis 初始化 + cache helper
internal/config 配置层(viper 加载 + 30 个配置块)
internal/seed 种子数据(13 角色 / 资源树 / Casbin / 字典)
internal/migrate AutoMigrate + 字典完整性检查
internal/guard 框架原语可达性守卫:每个 internal/pkg 包都得有调用方

⚠️ internal/pkg/ 里没有任何一个包 import internal/service / internal/model / internal/api / cmd —— 框架层不依赖业务层。这条由 server/examples/examples_test.go 的漂移网守着。
